# Steel Brothers gallery photos

Upload your REAL club photos to this folder on GitHub.

Name files using the date they were taken or published:

- 2026-10-08-ride-with-friends.jpg
- 2026-10-08-1830-meeting.webp
- 2026-10-09-new-motorcycle.png

Format: YYYY-MM-DD-description.jpg (optional -HHMM after the date).
Supported: JPG, JPEG, PNG, WebP, AVIF and GIF.

Why the date? Git does not preserve reliable original photo upload timestamps.
The site sorts by the DATE IN THE FILENAME (newest first), not by when a
file was edited or committed. Photos without date prefixes remain visible
but appear after all dated photos.

The homepage automatically displays the first three newest photos.
When there are more than three, the "Zobrazit více" button links to
https://steelbrothers.cz/gallery/ and that page shows the full collection.

No public uploads are enabled. Upload here through GitHub, or send photos
in ChatGPT to have them prepared and committed.

Before sharing photos, make sure everyone pictured agrees to public posting,
and remove GPS metadata if needed. Keep originals backed up privately.
